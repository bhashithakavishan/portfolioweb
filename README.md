# Bhashitha Portfolio — React + TypeScript + Vite + Framer Motion

A fully themed portfolio website with:
- **Hero section** (your exact component from bhashithak.netlify.app)
- **Light / Dark / System** theme toggle in the navbar
- **3 pages**: Home, About Me, My Works — all routed via React Router
- Animated with **Framer Motion** throughout
- **Typing animation** in the hero headline
- Responsive navbar with mobile drawer
- Services section, Experience timeline, Project grid, FAQ accordion, Social links, Contact footer

## Quick Start

```bash
npm install
npm run dev
```

Then open the URL printed (usually http://localhost:5173)

## Add Your Photo

Place your portrait cutout (transparent background, WebP or PNG) at:
```
public/images/img.webp
```
See `public/images/README.txt` for details.
